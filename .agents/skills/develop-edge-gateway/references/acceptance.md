## Windows 手工验收

1. 首次启动只加载演示设备，MQTT 与现场设备默认不启用。点击开始后能看到四个模拟点位、历史与状态变化。
2. 保存后重启配置保持；配置备份存在；损坏配置出现明确错误且文件不被覆盖。
3. 新增/编辑/删除设备与点位，运行期间禁用配置变更；停止后可继续编辑。
4. 打开多个实例仅允许一个使用同一运行目录。正常关闭停止可取消任务、释放串口和数据库。若原同步库未在关闭宽限内退出，确认有隔离告警、禁止同设备新会话，并在原调用最终退出后清理；不可把宽限超时写成已终止原生操作。
5. 实时质量、错误、趋势和日志与采集结果相符；CSV 中文、逗号与公式前缀正确。
6. 在 1366×768、1920×1080、3200×2000 及 100% / 150% / 200% DPI 检查主窗体、弹窗和滚动。
7. 逐项选择 12 个迁移驱动，设备参数和点位方法下拉能显示与保存；原枚举和参数默认值正确，诊断方法有标识，未支持写入的方法不能授权写入。

## 现场与平台验收

记录设备品牌、型号、固件、协议、地址表版本、线缆、串口/网络参数、网关硬件与测试时间。

- 分别验证 TCP、RTU 的各寄存区、符号、字节序、倍率、写入及读回。
- 中断设备网络/电源后恢复，验证质量、退避和其他设备不受影响。
- 停止 Broker 后持续采集，重启应用与 Broker，验证已入队数据补传、消息 ID 去重和容量告警。
- 使用有效 TLS 证书连接；错误证书、错误账户必须拒绝，日志不含密码。
- 验证磁盘空间不足、日志轮转、数据库备份恢复，以及预期设备/点位规模下持续 24–72 小时运行。
- 断电测试明确区分已持久化 outbox、尚未生成的周期快照、历史内存缓冲；程序不承诺尚未落盘数据零丢失。

## 当前明确范围

当前程序是 Windows 桌面网关，包含上游 `Plugins/Drivers` 全部 12 个工程迁移。关闭程序即停止采集；没有 Windows Service 守护进程、自动开机注册、多用户 RBAC、远程 RPC、OTA/VPN 或上游 Web/数据库迁移。FOCAS 原生运行库、Hsl 有效授权及 OPC DA COM 环境仍由现场准备。

上报采用周期最新值快照，历史按采集周期保存。队列满后暂停生成后续快照，继续现场采集和历史处理；未生成的中间快照不会在以后逐条还原。QoS1 属于至少一次交付，云端使用 `messageId` 去重。
