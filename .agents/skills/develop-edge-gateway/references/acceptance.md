## WinForms 自动化验收细节

固定驱动目录使用 `Items.AddRange` 同步装载，再按稳定驱动 Id 选择；不能依赖窗体建立 `BindingContext` 前的 `DataSource / SelectedItem` 初始化。显示窗体后检查驱动选择、参数值与枚举没有丢失。

在 Windows 逐个打开全部驱动的设备和点位编辑器，并遍历各页签。长参数页按真实键盘访问路径检查：先聚焦启用的公开输入控件并验证 `ContainsFocus`，再滚动到该控件、执行布局，检查控件与所有祖先的可见边界。禁用字段仍需检查，可将焦点移到滚动区外的固定按钮，不能通过启用或跳过字段使检查通过。`NumericUpDown` 作为整体滚动，再检查其内部文本框；不要把内部实现控件当作独立键盘停靠点。失败时保存当时的窗体截图和控件类型、名称、边界。

原因见 [.NET 8 ScrollableControl 源码](https://github.com/dotnet/winforms/blob/v8.0.32/src/System.Windows.Forms/src/System/Windows/Forms/ScrollableControl.cs)与 [ContainerControl 源码](https://github.com/dotnet/winforms/blob/v8.0.32/src/System.Windows.Forms/src/System/Windows/Forms/ContainerControl.cs)：程序滚动后进行布局时，容器可能再次把旧的活动控件滚入视图。禁止通过放宽边界断言掩盖焦点或实际裁剪问题。

构建记录应区分干净构建与增量构建；增量输出无警告不能代表迁入源码干净编译无警告。保留上游兼容 API 警告并记录其类别，不以全局抑制替代处理。

对 DPI 场景保存操作系统版本、实际屏幕分辨率、工作区、窗口大小、缩放百分比、`DeviceDpi`、验证方式和截图。人工调用 `Scale`、注入 DPI 消息或只缩小窗体的检查只证明受控布局行为；不得作为真实显示器缩放、跨屏或全部 Windows 版本通过的证据。真实 DPI 检查还应核对窗口 DPI 与目标显示器的设置一致。

在已经显示且缩放过的设备编辑器中切换全部驱动，再次检查新生成的参数字段和枚举；检查关闭后重开编辑器、重新显示隐藏页签与往返 DPI 后布局仍一致。图标尺寸、表格表头/行高/单元格内边距、下拉列表与趋势图坐标文字应纳入截图检查。至少在最小可用工作区验证长驱动参数的第一项和最后一项，以及固定确认/取消按钮。

对自动保存的界面路径使用可等待的操作辅助方法，等待实际保存及运行时应用完成再断言；不能触发 `async void` 后立即判断，也不能阻塞 UI 线程等待 Task。核对内存配置、原子保存后的文件以及重新加载结果。用隔离测试目录中的受控文件锁等真实失败条件验证设备、点位、CSV 弹窗保持打开且输入可继续修改，原配置和运行会话保持，测试结束恢复文件和运行时配置。

平台与 UA 分别保存独立草稿，未应用输入不影响按已保存设置启动；设备变更不得覆盖任一草稿。一台设备仍运行时拒绝通道等全局配置、平台设置、UA 设置及整份配置替换；设备全部停止后从最新配置克隆，仅覆盖本次页面负责的字段，不撤销后来设备变更或另一页面草稿。完整导入须确认替换两套草稿。配置保存成功与 UA 启动成功分别断言，端口/证书/密码错误显示且允许修正后重试。

写入弹窗分别验证非模态 Close 后已释放控件和真实 ShowDialog 返回后的确认结果，保留操作值、核对开关、超时与容差全部期望。不能因控件释放后 Text 回退而放宽断言；确认结果应独立于控件生命周期，生产写入仍经过目标确认和运行时权限检查。

## Windows 手工验收

1. 首次启动加载默认演示与未启用的 TCP/RTU 示例，自动启动、MQTT、RPC/远程写和 UA 服务默认关闭。点击“演示机组”行的“启动”后能看到四个模拟点位、历史与状态变化；首次直接启动后重开程序，设备/点位 ID 保持。
2. 设备和点位编辑确认后自动保存并在重启后保持；取消无修改，备份存在。校验或文件写入失败时弹窗不关闭且保留输入，原配置与会话不变；损坏配置出现明确错误且文件不被覆盖。
3. 两台启用设备分别启动，停止 A 后 B 持续采集且允许授权写入；A 的旧值标记为已停止/不确定且禁止写入。最后一台停止后共享任务正常结束。B 运行时可新增、编辑、删除停止的 A 及其点位；新增/保存停止设备不自动启动。运行 A 的变更只重启 A，B 持续采集、历史及上报；禁用/删除 A 只停 A。
4. 打开多个实例仅允许一个使用同一运行目录。正常关闭先停止 UA 端点及其连接/订阅，再停止设备与共享任务、释放串口和数据库。若原同步库未在关闭宽限内退出，确认有隔离告警、禁止同设备新会话，并在原调用最终退出后清理；不可把宽限超时写成已终止原生操作。
5. 实时质量、错误、趋势和日志与采集结果相符；CSV 中文、逗号与公式前缀正确。
6. 按 [DPI 与视觉验收矩阵](winforms-dpi.md#6-验收矩阵) 检查 1366×768、1920×1080、2560×1440、3200×2000 与 100% / 125% / 150% / 175% / 200% 缩放。检查总览、设备、实时、历史、平台、日志、通信诊断七个主页面及全部编辑器，包含五类矩阵弹窗、图标、自绘趋势和滚动；100% ↔ 150% ↔ 200% 跨屏往返后不得累计放大或缩小。等效工作区矩阵不替代这些真实 DPI 操作。
7. 逐项选择 12 个迁移驱动，设备参数和点位方法下拉能显示与保存；原枚举和参数默认值正确，诊断方法有标识，未支持写入的方法不能授权写入。
8. 平台和 UA 草稿在采集期间分别可编辑或重置，未应用时启动使用已保存设置；普通设备保存保留两套草稿。设备全停后应用只更新本页字段，后续新增设备与另一页草稿仍在；设备运行时全局应用与整份配置替换不能执行。
9. CSV 先以 20 列追加，再以旧 17 列按名称更新，核对 ID、缺席点位及缺失扩展字段保留；显式空表达式可以清除，数值扩展空值或末行/地址错误拒绝整批。关上传后实时值与历史继续，后续快照排除该点，已有 outbox 不被清空。
10. 通信诊断分别核对设备读写/失败批次、耗时、降速、队列满、持久化失败、平台发送确认和 RPC 状态。批次数不当作物理帧数；PUBACK 与 ThingsCloud 属性成功响应各按其语义显示，均不作为所有下游业务已完成的证据。
11. 验证通道互斥和跨通道持续采集、点位不同周期与故障降速恢复；筛选后仍按稳定 ID 操作目标。复制设备保留完整点表和参数，生成新设备/点位 ID，默认禁用且不自动采集；同串口冲突仍拒绝。
12. 对停止和运行设备分别执行真实连接诊断/单点读取，确认会话与资源语义。手动写入只下发一次并展示实际读回、质量、提交状态、次数和结果；超时/取消不能解释为设备一定未执行。表达式预览与真实采样一致，错误标 Bad，表达式点不允许写入。
13. 切换周期、仅变化、变化加心跳，验证累计死区、质量变化、心跳保留原时间和重启初值。五平台分别核对真实主题、子设备状态、遥测及 RPC 回复；默认拒写，授权后重复同 ID 重放、改内容/方法拒绝、重启或不确定占位不重复下发，平台拒绝/超时不清 outbox。

## 现场与平台验收

记录设备品牌、型号、固件、协议、地址表版本、线缆、串口/网络参数、网关硬件与测试时间。

- 分别验证 TCP、RTU 的各寄存区、符号、字节序、倍率、写入及读回。
- 中断设备网络/电源后恢复，验证质量、退避和其他设备不受影响。
- 对实际使用的五平台模式分别验证主题、物模型与质量元数据、子设备通知、RPC 请求/回复和幂等；ThingsCloud 必须取得注册及属性应用成功响应，不能用通用 Broker 回环代替租户联调。
- 停止 Broker 后持续采集，重启应用与 Broker，验证已入队数据补传、设备/消息标识联合去重和容量告警；停止或删除设备的旧消息保持原载荷、时间与质量。
- MQTT 使用有效 TLS 证书连接；南向 `OPC.UaClient` 按现场目标服务器的安全策略与证书信任进行采集。错误证书或凭据明确失败，日志、配置与导出不含密码或私钥。
- 验证磁盘空间不足、日志轮转、数据库备份恢复，以及预期设备/点位规模下持续 24–72 小时运行。
- 断电测试明确区分已持久化 outbox、三种上报策略尚未落盘的最新值选择、历史内存缓冲与 RPC 写占位/完成记录；程序不承诺尚未落盘数据零丢失，未知写结果不能自动重下发。

## 当前明确范围

当前程序是 Windows 桌面网关，包含上游 `Plugins/Drivers` 全部 12 个工程迁移，以及通道/扫描/降速、真实诊断、一次写入与主动读回、受限单点表达式、五平台 MQTT/RPC。南向 `OPC.UaClient` 驱动继续保留，对外服务端工程、配置字段、界面及专用依赖已移除，不保留兼容层。这里对标的是 [Kepware 核心能力](../../../../docs/kepware-core-capabilities.md)，不声明具备 Kepware 全部产品、驱动、扫描模式、商业插件或协议一致性认证。

关闭程序即停止采集；没有 Windows Service 守护进程、自动开机注册、多用户 RBAC、OTA/VPN 或上游 Web/数据库迁移。共享物理串口多从站和跨点计算也不在当前完成范围。FOCAS 原生运行库、Hsl 有效授权及 OPC DA COM 环境仍由现场准备。

上报支持周期全量、仅变化和变化加心跳，均选择最新值，历史按实际采集扫描保存。新快照按设备/点位启用和上传开关过滤；停止但仍启用设备的旧值可带 `Uncertain` 进入快照，心跳不更新原采样时间。队列满后暂停生成后续快照，继续采集和历史；检查间隔内的瞬态或回压期间未生成的中间快照不会逐条还原。配置变化重建未入队选择，已开始的单次入队及已持久化原载荷不保证撤回。

所有 MQTT 模式保留至少一次语义。PUBACK 表示 Broker 确认；ThingsCloud 还要求匹配属性应用成功响应才删除 outbox，但仍不证明所有下游规则或入库完成。按平台使用消息 ID，分设备消息使用设备标识与消息 ID 联合去重。RPC 的持久幂等限于写命令审计：重复重放、不确定占位拒绝重写，读响应缓存有界且不跨重启。详细边界见 [平台接入与 RPC](../../../../docs/platform-protocols.md)和[遥测语义](../../../../docs/telemetry.md)。
