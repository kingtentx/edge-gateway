## WinForms 自动化验收细节

固定驱动目录使用 `Items.AddRange` 同步装载，再按稳定驱动 Id 选择；不能依赖窗体建立 `BindingContext` 前的 `DataSource / SelectedItem` 初始化。显示窗体后检查驱动选择、参数值与枚举没有丢失。

在 Windows 逐个打开全部驱动的设备和点位编辑器，并遍历各页签。长参数页按真实键盘访问路径检查：先聚焦启用的公开输入控件并验证 `ContainsFocus`，再滚动到该控件、执行布局，检查控件与所有祖先的可见边界。禁用字段仍需检查，可将焦点移到滚动区外的固定按钮，不能通过启用或跳过字段使检查通过。`NumericUpDown` 作为整体滚动，再检查其内部文本框；不要把内部实现控件当作独立键盘停靠点。失败时保存当时的窗体截图和控件类型、名称、边界。

原因见 [.NET 8 ScrollableControl 源码](https://github.com/dotnet/winforms/blob/v8.0.32/src/System.Windows.Forms/src/System/Windows/Forms/ScrollableControl.cs)与 [ContainerControl 源码](https://github.com/dotnet/winforms/blob/v8.0.32/src/System.Windows.Forms/src/System/Windows/Forms/ContainerControl.cs)：程序滚动后进行布局时，容器可能再次把旧的活动控件滚入视图。禁止通过放宽边界断言掩盖焦点或实际裁剪问题。

构建记录应区分干净构建与增量构建；增量输出无警告不能代表迁入源码干净编译无警告。保留上游兼容 API 警告并记录其类别，不以全局抑制替代处理。

对 DPI 场景保存操作系统版本、实际屏幕分辨率、工作区、窗口大小、缩放百分比、`DeviceDpi`、验证方式和截图。人工调用 `Scale`、注入 DPI 消息或只缩小窗体的检查只证明受控布局行为；不得作为真实显示器缩放、跨屏或全部 Windows 版本通过的证据。真实 DPI 检查还应核对窗口 DPI 与目标显示器的设置一致。

在已经显示且缩放过的设备编辑器中切换全部驱动，再次检查新生成的参数字段和枚举；检查关闭后重开编辑器、重新显示隐藏页签与往返 DPI 后布局仍一致。图标尺寸、表格表头/行高/单元格内边距、下拉列表与趋势图坐标文字应纳入截图检查。至少在最小可用工作区验证长驱动参数的第一项和最后一项，以及固定确认/取消按钮。

对自动保存的界面路径使用可等待的操作辅助方法，等待实际保存完成再断言；不能触发 `async void` 后立即判断，也不能阻塞 UI 线程等待 Task。核对内存配置、原子保存后的文件以及重新加载结果。用隔离测试目录中的受控文件锁等真实失败条件验证写入失败时原配置保持，测试结束恢复文件和运行时配置。平台有未应用输入时，设备变更不得覆盖输入；应用平台时，不得撤销此后新增的设备。

## Windows 手工验收

1. 首次启动加载默认演示与未启用的 TCP/RTU 示例，自动启动与 MQTT 默认关闭。点击“演示机组”行的“启动”后能看到四个模拟点位、历史与状态变化；首次直接启动后重开程序，设备/点位 ID 保持。
2. 设备和点位编辑确认后自动保存并在重启后保持；取消无修改，备份存在，校验或文件写入失败保留原配置；损坏配置出现明确错误且文件不被覆盖。
3. 两台启用设备分别启动，停止 A 后 B 持续采集且允许授权写入；A 的旧值标记为已停止/不确定且禁止写入。最后一台停止后共享任务正常结束。任意设备运行时配置只读，全部停止后可编辑；平台未应用输入可应用或重置，不能污染已保存的设备。
4. 打开多个实例仅允许一个使用同一运行目录。正常关闭停止可取消任务、释放串口和数据库。若原同步库未在关闭宽限内退出，确认有隔离告警、禁止同设备新会话，并在原调用最终退出后清理；不可把宽限超时写成已终止原生操作。
5. 实时质量、错误、趋势和日志与采集结果相符；CSV 中文、逗号与公式前缀正确。
6. 按 [DPI 与视觉验收矩阵](winforms-dpi.md#6-验收矩阵) 检查 1366×768、1920×1080、2560×1440、3200×2000 与 100% / 125% / 150% / 175% / 200% 缩放。检查主窗体、全部编辑器、手动写入弹窗、图标、自绘趋势和滚动；100% ↔ 150% ↔ 200% 跨屏往返后不得累计放大或缩小。
7. 逐项选择 12 个迁移驱动，设备参数和点位方法下拉能显示与保存；原枚举和参数默认值正确，诊断方法有标识，未支持写入的方法不能授权写入。

## 现场与平台验收

记录设备品牌、型号、固件、协议、地址表版本、线缆、串口/网络参数、网关硬件与测试时间。

- 分别验证 TCP、RTU 的各寄存区、符号、字节序、倍率、写入及读回。
- 中断设备网络/电源后恢复，验证质量、退避和其他设备不受影响。
- 停止 Broker 后持续采集，重启应用与 Broker，验证已入队数据补传、消息 ID 去重和容量告警。
- 使用有效 TLS 证书连接；错误证书、错误账户必须拒绝，日志不含密码。
- 验证磁盘空间不足、日志轮转、数据库备份恢复，以及预期设备/点位规模下持续 24–72 小时运行。
- 断电测试明确区分已持久化 outbox、尚未生成的周期快照、历史内存缓冲；程序不承诺尚未落盘数据零丢失。

## 当前明确范围

当前程序是 Windows 桌面网关，包含上游 `Plugins/Drivers` 全部 12 个工程迁移。关闭程序即停止采集；没有 Windows Service 守护进程、自动开机注册、多用户 RBAC、远程 RPC、OTA/VPN 或上游 Web/数据库迁移。FOCAS 原生运行库、Hsl 有效授权及 OPC DA COM 环境仍由现场准备。

上报采用周期最新值快照，历史按采集周期保存。队列满后暂停生成后续快照，继续现场采集和历史处理；未生成的中间快照不会在以后逐条还原。QoS1 属于至少一次交付，云端使用 `messageId` 去重。
