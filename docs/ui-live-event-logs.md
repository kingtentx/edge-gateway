# 运行日志实时刷新与级别颜色

2026-10-29 用户要求：运行日志取消分页、列表自动刷新，不同级别用不同颜色标识。

页签顺序按后续要求调整为“运行日志 / 采样数据 / 日志设置”，首次进入默认选中运行日志。固定顺序在 Designer 设置；设置与采样检查按页签对象定位，避免依赖旧序号。

- 运行日志不绑定分页器，隐藏共用 Designer 的分页底栏；采样数据仍绑定原分页器。
- 进入运行日志页后，主窗体已有刷新周期约每 2 秒调用应用层文件查询。默认最近一小时，保留最多条数、扫描量、结果载荷限制；仍按时间倒序显示。页面不可见、导出选择文件中、有查询/导出正在执行时不发起新查询。
- “暂停刷新 / 实时刷新”按钮在 Designer 创建。编辑时间范围或执行手动查询会暂停实时刷新；“最近一小时”在运行日志页恢复实时刷新。其他筛选条件在下一次刷新生效；查询期间改条件时，不接受过期的自动查询结果。
- 调试灰色、信息蓝色、警告橙色、错误红色，使用官方主题颜色和 CellText，保留中文级别文字，不自绘皮肤。
- 用日志 JSON 内容和重复序号定位记录，文件轮转重命名不改变记录身份。刷新保留选择、列和滚动；在顶部时显示最新行，向下查看时保持原记录所在视口。达到有界条数后，已离开结果集的记录无法继续保留。
- 双击详情通过绑定记录定位，避免采样分页或刷新后用可见行号误取记录。导出在打开文件对话框前冻结当前显示的查询快照，新的日志不会混入导出。
