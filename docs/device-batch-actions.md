# 设备勾选与批量操作

设备列表首列使用 AntdUI `CellCheckbox`，勾选与当前高亮行独立。表头以 AntdUI Checkbox 替代“勾选”文字，点击全选/取消当前全部筛选结果（含全部页），部分勾选显示半选；工具栏的“批量操作”提供启动、停止、启用、禁用、复制、删除六项，移除菜单中的勾选筛选结果和清空勾选。摘要始终显示勾选数量。

- 勾选按稳定设备 ID 保存，翻页、刷新、配置保存后保留；筛选或删除后清除已不在筛选结果内的勾选。清除筛选不会恢复之前清除的勾选。
- 菜单打开时冻结目标 ID，切换高亮行不改变批量目标。鼠标点选或在复选框单元格按 Space/Enter 切换勾选；执行期间禁止改动勾选和重复执行。
- 启动、停止逐台通过 Application 命令执行，不以全局启动/停止替代。未启用设备不自动启用，已达到目标运行状态的设备跳过；逐台记录成功、跳过原因、失败原因，底部反馈可展开完整结果，运行日志保留汇总。
- “启动成功”表示发起采集，不代表驱动已连接，实际结果仍看采集状态。
- 批量启用/禁用通过 `SetDevicesEnabledAsync` 在应用命令锁内读取最新配置，仅更新目标 Enabled，一次完整校验、原子保存并应用；重复 ID 去重。目标不存在、校验或保存失败时不部分提交。并发编辑的名称、点位与其他参数保留。
- 启用不自动启动；禁用停止对应运行设备，未勾选设备继续运行。平台草稿不被覆盖。

表头复选框在 Designer 中真实创建并挂入表格控件树，按首列表头实际矩形居中定位，跟随列宽及滚动；空结果与操作忙碌时禁用，支持 Space/Enter。固定列和菜单触发器由 `DevicesPageView.Designer.cs` 创建；不自绘复选框。批量操作不是设备协议批处理，不绕过单设备生命周期锁。
