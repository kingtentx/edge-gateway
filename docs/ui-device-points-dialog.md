# 设备列表与点位弹窗

日期：2026-10-27。

设备页改为单列表布局，删除上下分栏和主页面点位表。顶部白色区域第一行按搜索、设备分组、通信通道排列，支持输入即筛选和重置；第二行提供添加设备、导入/导出、通道管理、所选设备操作、诊断所选设备与数量。过滤条件支持窄窗口换行，设备表填满剩余空间。

每个设备行新增“查看点位”链接，保留启动、停止、配置及设备信息。链接以事件行的稳定设备 ID 打开独立点位弹窗，双击操作列不会重复触发。弹窗标题显示设备名称和驱动/点位数量，提供点位搜索、新增、编辑、单点读取、导入/导出、模板和删除；名称、地址、类型、单位、权限、启用/上传、读取方法、寄存区、字节序、换算、周期及死区按驱动显示，双击点位进入完整配置。

弹窗打开期间固定设备 ID；主列表选择或刷新不能改变点位操作目标。点位保存仍通过 Application 原子提交，失败保留编辑器输入；编辑器、文件对话框及诊断/删除提示以点位弹窗为拥有者。弹窗底部显示操作反馈，提交中不能关闭。关闭后释放设备上下文，主窗口释放时同时释放点位窗体。

固定点位控件从 DevicesPageView.Designer 迁至 DevicePointsDialog.Designer，包含原有列结构和操作按钮；运行时不重组或搬运控件。新增窗体提供无服务访问的设计时构造，并在项目中声明 Designer 从属关系。源码迁移完成；Visual Studio 设计器往返未执行。
