# 实时监控设备树与离线显示

2026-11-01：实时监控采用左右布局。左侧为分组筛选及 AntdUI Tree（全部设备、分组、设备）；选择分组显示该组点位，选择设备显示该设备点位。右侧保留点位名称/地址搜索、读写标识、写入入口、分页及可拖动表格列。

## 刷新规则

- 显示所选范围内全部已配置点位。没有采样记录时，数值和时间显示“—”。
- 只有设备已启用、状态为 Running、点位已启用时，才持续更新其数值和采样时间。
- 停止、连接中、重连、异常或禁用时保留最后显示的值和时间；状态和质量继续反映当前情况，离线旧值不会保持“正常”质量。首次进入页面可加载运行时保留的最后一条采样，后续离线更新不推进值与时间。
- 恢复在线后继续接受新采样；其他设备是否在线不影响当前设备刷新。显示缓存仅用于界面，不回写采集运行时、数据库、日志或历史查询。
- 在线读取产生的坏质量仍正常展示。离线时禁用手动写入，提交写入前再次检查设备状态。
- 按设备/点位稳定 ID 维护显示状态；删除点位清除缓存，地址变化不复用旧地址的数值。定时刷新不重建树节点，并沿用公共表格的选择、页码、列宽和滚动保持机制。

## 界面与验证边界

固定两栏容器、分组框、树、工具栏和表格列均在 RealtimePageView.Designer.cs 中创建。动态树节点和数据行由应用快照绑定，窗体不执行协议读取；沿用现有页面刷新周期。

新增 RealtimeDisplayStateTests 和隔离桌面 RealtimeBrowser 场景，覆盖离线冻结/恢复、质量、未采样点位、分组/设备/搜索、分页选择保持、模拟设备启停以及宽窄布局。

本次源码修改尚未执行构建、自动测试、架构门禁或 Windows 界面验证，等待用户授权。未连接真实设备或实际外库，未修改现场配置；Designer 代码结构已调整，但设计器可编辑性尚未人工验收。
