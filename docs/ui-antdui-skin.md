# AntdUI Demo 浅色皮肤与列表空间

## 参照与范围

用户于 2026-10-27 指定 [AntdUI/AntdUI-Demo](https://github.com/AntdUI/AntdUI-Demo) 为界面风格参考。本轮读取其 `MainWindow.Designer.cs` 和 `assets/screenshots/Table.png`，固定参考提交 `0a66f848f1e218ca975c69c3b9a4312c6316db6f`。参考其白色导航、浅灰表头、蓝色选择态、线性图标和细分隔线；项目仍使用 .NET 8 WinForms 和 AntdUI 2.4.16。

## 实现

- 主窗体改为白色图标导航与浅灰工作区，导航选中项使用浅蓝背景和蓝色文字。正文保持 10pt，页面与弹窗标题减少装饰性占用。
- 八个页面、配置及导入弹窗统一表头、间距、按钮和分组配色。表头选择色显式设置为浅灰，避免出现操作系统的整块亮蓝色；表格行高按实际文字高度计算，逻辑最小值由 38 调整为 34。
- 设备/点位列表放入 Designer 实例化并挂载的横向 `SplitContainer`。拖动分隔条调整高度，双击恢复默认比例；刷新不改动用户比例或所选行身份。比例只在当前窗口内保留，不写业务配置。
- 设备页保留至少 620 逻辑像素的布局高度，较矮窗口提供页面滚动；缩短标题、工具栏和表单留白，让数据区获得更多空间。
- 共享配置弹窗默认客户区调整为 780 × 700 逻辑像素，仍由 `DpiAwareForm` 限制在实际工作区内。减少字段行与页签留白，保存/取消区固定在底部，长表单继续滚动。
- 固定控件与新分隔容器真实保留在对应 `Designer.cs` 中。驱动参数、schema 映射、数据行、曲线与元数据仍动态绑定。业务提交与失败输入保留流程未改变。原生表格、页签和选择器继续保留现有键盘、列滚动和焦点行为，并采用统一主题；并非替换全部原生控件类型。
- 保留开始前用户对 MainForm Designer 的整理与版次标签删除；清理对应后台悬空引用。现有额外 MainForm 分部类 `.resx` 使用文件名区分资源，避免资源名称冲突。其余用户已有 `.resx` 文件不改写。
