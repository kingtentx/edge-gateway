# 通信诊断 CSV 导出

2026-10-29：用户要求通信诊断导出改用 CSV，并确认使用导出时间命名：`通信诊断_yyyyMMdd_HHmmss.csv`，例如 `通信诊断_20261029_223000.csv`。

- 点击导出时经应用层刷新诊断，冻结完整诊断列表后打开保存窗口，不受表格分页、当前选择或保存窗口期间的定时刷新影响。
- 中文表头：导出时间、网关标识、诊断项目、当前值 / 最近事件、说明。内容与通信诊断列表一致，包含上报、MQTT、RPC、数据库写入及设备通信统计。
- 文件名使用采集服务器本地系统时间；CSV 导出时间包含毫秒和时区偏移。这是当前状态快照，不声称是某个起止范围的历史记录。
- 使用 UTF-8 BOM、CRLF；复用现有 CsvLine 的逗号/引号/换行转义及公式前缀保护。保存窗口默认扩展名为 csv，并保留覆盖确认。
- 本轮完成源码及手动差异审查，未执行编译、导出测试或界面验证。历史布局测试不作为本次 CSV 数据正确性验证。
