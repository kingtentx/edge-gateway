# 操作菜单与紧凑表单对齐

2026-10-28，按用户截图及进一步缩窄控件的要求调整。

## 实现

- 设备行启停按钮改用 `TextRenderer` 的水平、垂直居中，统一网格的 GDI 字体度量；绘制前按单元格底色混合官方禁用透明色，保留绿色启动、红色停止、禁用灰色及原生焦点框。
- `CommandMenuButton` 使用官方 `ShowArrow=true`、`IsLink=true` 显示向下箭头，打开后指向上方，关闭后恢复。三个操作入口（设备导入/导出、所选设备操作、点位操作）统一生效。
- 弹出项从原生 ToolStrip 迁移为真正的 `AntdUI.ContextMenuStrip`，采用现有 2.4.16 的默认圆角、留白、悬停、分隔和阴影。F2 放在独立右侧说明列；危险操作使用官方 Error 令牌；禁用项显示简短原因，完整原因保留在无障碍描述中。
- 菜单打开时捕获目标设备/点位，执行时重新检查权限；关闭、重复执行保护、错误反馈保持。触发按钮公开下拉无障碍角色与所捕获的命令子项；方向键、Enter、Escape 由官方菜单处理。
- 普通单行文本、数值、日期、下拉统一 240 逻辑像素上限，长地址、主题、Token、表达式和写入值由 Designer 显式设为 400。较窄筛选区继续受父布局约束，开关不拉伸，表格、多行内容不套单行宽度。固定控件仍由 Designer 创建，动态参数复用公共 InputFrame。
- `GatewaySelect.ListAutoWidth=false`，展开选项宽度跟随输入区域，避免短选项产生窄弹出层。字号与输入高度保持不变。

官方行为依据为已使用的 AntdUI 固定提交 `3167b26361e161cb26d628be5bd0532b9e6e92ce` 中 Button、ContextMenuStrip 与 LayeredFormContextMenuStrip 源码，未升级依赖或改动核心业务。
