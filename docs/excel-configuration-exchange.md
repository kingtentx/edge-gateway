# 设备与点位 Excel 导入导出

更新日期：2026-10-26。使用 `.xlsx`；旧 `.xls` 请先在 Excel 中另存为 `.xlsx`。

## 操作入口

“设备与点位”顶部的“设备导入导出”包含导入设备 Excel、导出所选设备、导出全部设备和下载模板。所选设备导出包含其全部点位和关联通道，不受点位搜索条件影响；导出全部不受设备筛选影响。

点位区域的“点位操作”提供独立的 Excel 导入、导出和模板。模板中提供示例行，请修改为实际设备/点位信息；新增设备示例默认停用。没有选中设备时不可导入或导出设备点位，但可下载模板。

原 JSON 配置交换保留在“更多操作”；点位文件对话框仍可选择 CSV。Excel 设备文件和独立点位文件结构不同，请分别使用对应入口及模板。

## 工作簿结构

| 工作表 | 内容 |
|---|---|
| 填写说明 | 格式、限制、更新规则和枚举可选值 |
| 设备 | 设备键、通道键、设备标识、名称、分组、驱动、启用状态、采集/降速参数、网络及串口参数 |
| 通道 | 通道键、通道标识、名称、请求间隔和说明 |
| 驱动参数 | 设备键、参数名、参数值，每个参数一行 |
| 点位 | 设备工作簿包含设备键及点位标识；独立点位工作簿不含这两列。其余包含名称、地址、类型、寄存区、字节序、读写方法、启用/上传/写权限、倍率/偏移/表达式、周期/死区、单位、报警上下限和说明 |

设备键和通道键仅用于工作簿内部关联，可用任意唯一文本；关联行须填写相同键。导出时使用对象标识作为键。设备、通道、点位“标识”列是软件稳定 Guid：更新请保留；新增副本须清空设备和点位标识，并为工作簿内新对象使用不同设备键。新增通道还须清空其标识并使用不同通道键。空标识在读取时生成，预览与提交使用同一标识。

保留全部工作表名称和表头；允许调整列顺序，不接受未知或重复表头。地址、标识、驱动参数以文本保存，保留前导零及长整数。数值使用小数点，布尔使用“是/否”（也接受 true/false、1/0）。数值不可空，报警上下限可空。枚举使用填写说明中的英文名称，避免依赖内部数字编码。公式和错误单元格拒绝，请先粘贴为值；字符串形式的 `=...` 按原文本保存。

设备工作簿包含驱动参数，可能包含授权码或驱动专用密码；不包含网关平台账号、数据库连接及采集结果。

## 导入与保存

- 设备追加模式拒绝已存在的设备标识；按标识更新模式覆盖文件内设备设置，按点位标识合并点位，按参数名合并驱动参数。文件未列出的设备、点位及参数保留，删除仍使用界面操作。
- 相同标识的通道参数必须完全一致，否则拒绝导入并提示在通道管理修改。新通道要求全部设备停止，纯设备/点位变更保持已有运行中配置规则。
- 独立点位导入可追加或按名称更新，名称匹配不区分大小写，更新保留现有点位标识，文件未列出的点位保留。
- 先预览全部校验结果，设备预览列出新增/更新及保存后点位数；点位预览最多显示 500 行，校验与保存覆盖完整候选。校验、驱动缺失或保存失败均不进行部分提交，预览窗口保留。
- 确认后 Application 在命令锁内基于最新配置重新合并，经完整驱动/配置校验和 SQLite 原子保存后应用；保留其他设备、平台、数据库和日志设置。新设备保持停止，仅重启实际变更且原先运行的设备。

单文件最多 8 MiB，解压内容最多 64 MiB、512 个 ZIP 条目；每工作表最多 20000 数据行、64 列；最多 500 台设备、500 通道、每台设备 2000 点。超限请分设备导出或拆分模板。写入临时文件成功后才替换目标，失败或取消不破坏既有导出文件。
