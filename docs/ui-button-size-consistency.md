# 普通操作按钮尺寸一致性（2026-11-01）

用户指出数据库“复制为新写入组”与同排按钮大小不同，并要求检查其他页面。

## 原因与修正

相同 GatewayButton 类型不代表相同可见边框。普通按钮在 Designer 中使用 Height=38、Padding=(10,4,10,4)；部分后增按钮仅设置 AutoSize / MinimumSize，缺少 Height 和 Padding，默认测量及可见边框就与相邻按钮不同。缺少 Margin 时，也会造成同排对齐、换行间距不同。

已统一数据库复制写入组、设备数据去向、实时清除筛选/点位详情、历史快捷时间、诊断全部设备、平台固定操作、分组/通道管理，以及数据去向、设备点位关闭、自定义驱动参数和错误字段定位按钮的尺寸设置。固定属性仍在对应 Designer 中声明。按钮随文字内容保留不同宽度，统一的是高度、内边距和同排对齐；Default / Primary 及禁用状态继续使用官方主题。

导航折叠的图标按钮、下拉菜单触发器与表格内启停按钮保持各自组件用途和尺寸规则。未改变采集、配置保存或数据库写入流程。

## 验证

本轮完成源码阅读和手动差异审查。已提出 Release 编译及后台 ButtonAppearance 定向计划，待用户明确授权后执行；不引用上次通过记录作为本轮结果。计划按实际可见边框检查八个页面及页签的同排按钮高度和对齐，并检查数据去向与设备配置弹窗；保留宽窄窗口、官方状态及模拟设备启停检查。
