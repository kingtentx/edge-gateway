# Debug 后台残留与 MSB3027

日期：2026-10-27。

## 原因

本机 VS 构建报告 `CNC.Fanuc.dll` 无法复制、重试 10 次后失败。占用者为当前 Debug 输出目录下的 `EdgeGateway.WinForms.exe --worker`（PID 11880），界面父进程已经退出。独立 Worker 继续持有采集宿主与已加载程序集，VS 停止调试只结束界面进程，因此重新生成无法覆盖 DLL。

## 处理与开发行为

先通过当前用户命名管道查询后台 `IsRunning=false`，再发送 `worker/Shutdown`，等待进程正常退出。本次没有强制结束进程，也没有删除或修改配置库、驱动与日志文件。

Debug 入口现在直接使用 `GatewayHost` 托管采集，宿主与界面共用一个进程；VS 停止调试时整个进程退出，不再遗留由该界面启动的独立 Worker。正常退出仍由宿主停止任务并释放资源。普通 Debug 启动不启用烟测故障注入。

Release 保持独立 Worker，界面退出或崩溃后可重新连接已有后台。窗口关闭按钮仍隐藏到托盘；需要释放程序文件供构建或部署时，应从托盘选择“退出网关”，等待退出完成。Debug 的窗口仍在托盘中运行时，也需要先退出才能重新生成；本次不保证强制停止调试能完成设备清理或日志排空。

已运行的旧版后台不能靠源码修改自动退出。若再次遇到此错误，先确认报错进程路径与实际采集状态，通过托盘正常退出；不要按进程名称批量强制结束其他部署。

## 本次验证状态

已完成源码阅读、手动差异审查和当前残留进程的正常退出。按仓库测试确认约定，尚未执行构建、自动测试、静态验证脚本或 Windows 界面烟测；当前问题的文件占用已解除，修改后的启动行为仍待验证。
