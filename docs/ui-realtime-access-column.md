# 实时监控读写标识

2026-10-29：在实时监控表格“单位”和“质量”之间增加“读写”列，固定列在 RealtimePageView.Designer 中创建，使用现有 AntdUI 表格布局。

每次实时刷新按设备 ID 和点位 ID 从当前配置解析 Writable，显示“只读”或“读 / 写”，与点位管理一致。标识表达配置权限，设备停止不将可写点改成只读；真正写入继续由原有设备运行、启用及可写校验控制。样本在当前配置中找不到对应点位时显示“—”，不推测权限。

沿用稳定 ID 更新行，配置权限变化可随刷新更新显示。历史表格与历史导出不增加当前配置权限字段。

本次完成源码和手动差异审查，未执行编译、测试或界面验证；此前布局验证不作为本次新增列及数据绑定的通过证据。
