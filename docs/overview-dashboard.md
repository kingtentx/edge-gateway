# 首页设备健康与服务器辅助信息

2026-10-25，保持 .NET 8 / WinForms，配置 schema 不变。

## 页面层级

1. 顶部四张设备卡片：设备总数、在线设备、异常设备、停止设备。
2. 中部采集健康：启用/未启用设备、启用点位、在线率、正常/异常/不确定/待采集点、连接中/重连中/故障；相邻区域显示平台连接、待补传、数据库及日志错误状态。
3. 设备与点位、实时监控和通信诊断快捷入口。
4. 底部服务器资源区：主机名、逻辑处理器数；CPU、内存各用一张数值与趋势卡片展示，磁盘逐盘显示容量条及可用/总容量。宽窗口双列趋势，窄窗口单列，完整内容纵向滚动可达。

首页没有设备行列表，操作与明细统一在设备与点位页。卡片和健康区域随可用逻辑宽度换列，低高度窗口通过页面滚动访问完整内容，不缩小字号。

## 指标口径

- 总数：全部已配置设备，包括停用设备；停止数包含未启用及没有活动运行状态的设备。
- 在线：启用设备处于 Running 状态；在线率分母为启用设备数，无启用设备时显示横线。
- 异常：重连、故障，或 Running 状态带采样错误的设备。因此部分采样错误设备可同时计入在线和异常，四张卡片不应简单相加。
- 点位统计仅覆盖启用设备下启用点位；停止设备历史样本不再计入正常/异常，显示待采集。删除、停用或设备身份不匹配的采样被排除。当前质量沿用运行时真实状态，不另造成功缓存或新增采样超期判定。
- 数据库异常统计已启用连接的当前错误；日志取实际文件错误。平台未启用、未连接及已连接分别显示。
- CPU 采用两次 Windows `GetSystemTimes` 之差，内核时间包含空闲时间，扣除空闲后得到整机区间使用率；首次读取没有基线时不显示 0%。超过 64 个逻辑处理器时明确显示不可用，避免把一个处理器组冒充整机。
- 内存来自 `GlobalMemoryStatusEx` 的物理内存总量与可用量，内存及磁盘容量统一显示为 M（1 M = 1024 × 1024 字节）；CPU、内存达到 85% 提示偏高。
- 磁盘使用总容量和总剩余空间，显示容量使用率，非磁盘 I/O 忙碌率。仅列本地固定磁盘，达到 90% 提示空间偏紧；单盘失败显示不可用并保留其他盘读数。
- 首页显示时随原 1 秒界面定时器发起资源读取，上一请求未结束时不并发重复发起。读取独立于设备汇总刷新，错误显示在资源区，退出后不更新已释放控件。切换到其他页面不继续发起资源读取；CPU 为相邻有效读取之间的平均值。

系统 API 依据：[GetSystemTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getsystemtimes)、[GlobalMemoryStatusEx](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-globalmemorystatusex)。

## 服务器资源图表（2026-10-26）

- CPU、内存显示当前百分比、正常/偏高状态及最近 60 秒面积折线，纵轴固定 0–100%，悬停查看采样时间和值；内存同时显示已用/总量。
- 曲线按快照时间绘制，仅保留最近 60 秒、最多 121 条读数。失败记录为空值，相邻采样超过 3 秒不连线；切换页面期间不补造数据。系统时钟回退时清理旧曲线，避免时间顺序错误。
- 磁盘按盘符保持控件身份并更新容量条，90% 起提示“空间偏紧”；某盘不可用时只清空该盘读数，并在下方显示原因。整次读取失败时清空所有当前数值，曲线保留历史并插入缺失记录。
- 所有数据仍由 Hosting 经 Application 提供；图表仅维护有界的界面历史，没有增加后台采样循环、工程引用、数据库或配置字段。
