# 设备表格列间距

2026-10-29 用户反馈设备表格列拥挤，按钮、文字和相邻表头之间缺少留白。

设备页 Designer 使用 AntdUI.Table 原生 `Gaps = new Size(16, 6)`，左右内边距由 12 增至 16 逻辑像素，保持上下 6。名称列最小宽度 220，启动/停止/配置各 76，点位管理 116，状态 104，点位/启用各 68，驱动 144，通道 128，分组/周期/连续失败各 112，最近成功 176，诊断 180。

全部尺寸按当前 DPI 由既有表格适配层换算。宽窗口按既有权重分配剩余宽度；窄窗口横向滚动，避免为塞下全部列而压缩文字和按钮间距。列宽仍可由官方表格拖动，行内容及命令继续使用现有 CellText、CellButton 和 CellLink。

## 本轮验证

用户已授权 Release 编译、隔离后台设备表格检查及同范围修复重跑。证据在 `artifacts/ui-device-columns/`，入口为 `scripts/smoke-test-winforms-background.ps1 -Scenario DeviceColumns`。

- `build-1.log` 编译通过，0 错误、420 项既有警告。`run-1` 检查通过；复核后将真实快照刷新后的列宽断言明确指向实际被拖动的启动列，再次编译复验。
- 最终 `build-2.log` 编译通过，0 错误、1 项既有 `GatewayWorkerClient.cs:283` CS8602 警告；`run-2` 检查通过，退出码 0、stderr 为空、5 张截图，`ProcessWindowVerified=true`、`InputDesktopSwitch=false`。
- 实际 `DeviceDpi=192`，窗口按 2200 → 1600 → 1000 → 1600 逻辑宽度往返。检查全部表头文字宽度与留白、四种操作单元格左右边界、窄窗口滚动到最后诊断列；人工复核宽窗口、常规窗口和窄窗口右侧截图。
- 表头实测 58 物理像素（29 逻辑像素），数据行 70 物理像素（35 逻辑像素）。通过官方表格鼠标处理器拖动启动列，由 152 增至 224 物理像素，重绘、分页及两次实际快照刷新后宽度和选择保持。
- 使用隔离配置和停止的模拟设备检查布局；未启动设备，未执行全量核心、真实设备、真实多屏 DPI 往返或 VS Designer 验证。
