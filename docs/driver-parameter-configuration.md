# 统一驱动参数配置

2026-10-30：按用户要求，内置驱动、迁移驱动和上传插件统一由 DriverDescriptor.Parameters 描述配置项，在同一“设备参数”列表配置，使用统一的参数编辑弹窗。原有 Modbus TCP/RTU 专用 UI 分支移除，连接参数定义移至各自驱动工厂。

参考 [iioter/iotgateway](https://github.com/iioter/iotgateway/tree/8de442a7dec52d2993d1e9667d799846936d681b) 的 ConfigParameterAttribute 机制，迁移基线仍为 `8de442a7dec52d2993d1e9667d799846936d681b`（见 driver-migration-manifest.json）。当前迁移适配器从属性获取名称、类型、默认值、枚举与关联关系；新插件通过同一 Parameters 契约声明参数。

- 列表显示参数名称、标识、值、类型与说明；参数值在统一弹窗输入，类型/选项按驱动说明填写，保存时由真实驱动校验；秘密值使用掩码。
- 原生连接字段通过 DeviceProperty 映射回既有强类型设备字段，保持真实驱动读取和 SQLite 存储不变；仅允许连接字段映射，不允许元数据改写设备身份或启停设置。
- 其他驱动参数保存在 Properties；原有 Id、周期和超时关联参数仍只读并从通用设置同步。
- 设备配置固定为“通用设置 / 扫描与恢复 / 设备参数”三个页签；删除 Modbus TCP 等所有独立驱动参数页。编辑默认打开设备参数，新增设备先选驱动；无声明参数的驱动也可在该列表添加参数。
- “设备参数”参照点位管理：顶部添加、编辑、删除与搜索，下方表格填满余下空间，双击行编辑。手工参数支持新增、编辑、重命名、删除名称/值。驱动声明参数的值在同一列表编辑，标识由插件契约决定，不能改名或删除；绑定和只读参数不可编辑。禁止与驱动声明参数同名、禁止空名和重名；值为字符串，由插件解释和校验。编辑草稿在切换驱动前保存，切回保留；保存配置前再次收集当前编辑值。
- 密码、Token、Secret、Authorization 等名称的值使用掩码。所有设置随设备整体保存；取消不修改原设备。插件必须实际读取同名参数才生效，参数编辑不能自动生成协议行为。
- 保留驱动校验。迁移驱动仍拒绝未声明的参数，以免拼写错误被静默忽略；后续插件可按自己的 Validate 实现接受扩展参数。

固定通用字段、设备参数列表与参数编辑弹窗保留 Designer；参数数据行按元数据动态绑定。现有设备 ID、点位、逐设备配置提交和平台草稿隔离语义保持。
