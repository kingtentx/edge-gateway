# 宽松导航、横向筛选和可调整表格

日期：2026-10-29。基于 main 的 `9279caa`，保持 AntdUI 2.4.16 与固定 Designer 控件树。

## 行为

- 按用户最终要求，展开侧栏保持正常的 184 逻辑像素宽度，不采用紧凑宽度；Menu 的 Gap 从 10 增至 14，itemMargin 从 6 增至 8，增加每项高度和上下留白。图标中线从 28 右移至 32 逻辑像素，增加左侧留白，收缩栏为 64；品牌、菜单、折叠按钮保持同一图标列。折叠按钮采用官方 MenuFoldOutlined / MenuUnfoldOutlined，按用户要求单独取消边框，保留焦点、键盘、提示与官方状态。
- 设备、实时、历史及两类日志中的 22 个固定筛选字段改为一行两列：标签在左、输入在右，纵向居中。标签按实际文字测量，输入保持紧凑宽度；外部 FlowLayoutPanel 在空间不足时整项换行。查询、重置和写入按钮取消旧的顶部标签占位。
- 表格问题来自迁移适配层：原 `AutoSizeColumnsMode` 只是未生效的元数据，所有列一直以固定最小宽度传入官方 Table；`EnableHeaderResizing` 也未开启。现在填充设置真正映射到 AntdUI，弹性列按可用宽度及 FillWeight 转成官方百分比列宽，保留官方 MinWidth 和固定操作列。窄窗口无法容纳全部最小列宽时继续横向滚动，不压缩文字。
- 所有 GatewayTable 共用官方表头拖动功能；AntdUI 保存当前实例中的拖动覆盖值，刷新和翻页继续使用该值。不承诺关闭程序后的列宽持久化。固定 ID、分页和业务数据处理保持原路径。
