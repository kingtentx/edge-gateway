# AntdUI 与 WinForms 设计器重构记录

更新日期：2026-10-27

## 本次确认的实施边界

采用“固定界面使用设计器，动态内容使用代码”。判断依据是控件结构是否随业务变化，而不是控件中显示的值是否变化。**新增了 Designer 文件、只放了空容器，或把 BuildPage/控件工厂搬进 Designer，都不等于设计器迁移完成。**

| 区域 | Designer 必须真实定义并挂入控件树 | 后台允许处理 |
|---|---|---|
| 主窗体 | 导航、顶栏、页面宿主、底部反馈区 | 导航事件、状态赋值、已有控件的响应式重排 |
| 设备与点位 | 工具栏及固定按钮、搜索框、表格和固定列、菜单入口 | 设备/点位行、选择与滚动恢复、操作状态、按目标生成的菜单项 |
| 数据库 | 固定页签、连接表单、测试/检查/保存按钮、映射表格框架 | 实际数据库表列表、按表结构生成的映射行、映射值与预览数据 |
| 平台与日志 | 固定分组、所有已知配置字段、页签和应用/重置按钮 | 枚举选项、草稿绑定、禁用/显示状态、日志结果与运行状态 |
| 配置弹窗 | 每个具体弹窗的固定表单、专属页签、标题和底部操作区 | 驱动专属通信参数、校验、业务调用及保存反馈 |
| 趋势与插件 | 图表/详情宿主、固定筛选区、刷新/管理按钮 | 曲线采样点、状态数值、插件参数与说明等元数据内容 |

设备名称、采样周期、数据库地址、Broker 主机、日志保留策略等字段属于固定表单，不得以“数据驱动”为理由留在后台创建。运行状态的数值可以动态更新，但固定状态标签和固定指标卡片也必须在设计器中存在。

## 源码组织要求

`Form/View.Designer.cs` 使用直接实例化、属性赋值、明确的父子关系和命名事件绑定，保留设计器能够维护的标准初始化结构。不得在 `InitializeComponent` 中调用控件工厂、通过循环/反射创建固定控件、访问运行配置或服务、执行数据库/驱动通信，或放入业务事件的匿名实现。

`Form/View.cs` 保存构造、响应式布局、事件处理、数据绑定及资源生命周期；业务保存仍通过 `IGatewayApplication`。固定控件只初始化一次，运行时不要再创建一套替代控件或重新包装整个固定表单。确需动态创建的参数放入明确命名的动态宿主，并负责取消、事件解绑和释放；刷新不应重建固定页面。

设计时构造必须不依赖真实数据库、驱动目录、采集进程或现场配置。共享基类具有 Designer 不能代替每个具体弹窗的固定字段迁移。静态表格的行数据不是控件结构，不把实时数据逐条固化进 Designer。

保持 .NET 8、Windows Forms、PerMonitorV2 和 96 DPI 逻辑基线；页面继承父窗体缩放，避免重复缩放。保持设备稳定 ID、配置原子提交、草稿保留、菜单与键盘操作、关闭到托盘和安全退出语义。采集调度、协议驱动、SQLite 配置和外部库写入不因界面重构而改变职责。

## 本轮源码调整

本轮基于 `2103428eb07316b03f11ebe69026226718a85836`，关联文件作为同一个提交更新 `main`，不创建开发分支，不强制更新引用。

- `MainForm.Designer.cs`：主窗体固定外壳改成明确的控件实例、属性和父子关系，去掉导航按钮工厂、循环装配、标签工厂及初始化方法内的业务 lambda。点击反馈的逻辑移到 `MainForm.DesignerInteractions.cs`。托盘与采集生命周期仍使用原有逻辑。
- `PlatformPageView.Designer.cs`：四个页签、全部 26 个固定配置输入、对应标签/分组/说明，以及应用、重置和驱动管理三个 AntdUI 按钮，直接定义并挂入控件树，不再只提供空字段容器。
- `PlatformPageView.cs`：提供现有控件的只读映射和布局调整，设计时构造不调用应用服务；处理 DPI 事件订阅与解绑。
- `MainForm.Platform.cs`：删除创建固定字段与分组的帮助器；只绑定已经存在的控件，保留平台草稿、全停后应用、重置、密码原值/掩码与应用层提交逻辑。
- 保留平台输入原有的 TextBox、ComboBox、NumericUpDown 和 CheckBox 类型，避免在未验证阶段同时改写字段绑定和校验契约。因此本轮不是全控件 AntdUI 替换完成的声明。

## 尚未完成与验收状态

之前增加了八个页面视图和共享编辑器 Designer，但仍有控件工厂、仅声明未挂入控件树、后台创建固定工具栏/表单及运行时重新包装控件等情况；不能将这些页面整体标记为“设计器可编辑已完成”。设备、实时/历史、数据库、诊断、日志和具体配置弹窗仍需按上述边界逐项完成。总览内部的固定指标卡片/图表区域也不能全部视为动态内容。

动态驱动专属参数、实际数据库字段映射行、设备/点位/日志行、曲线数据和插件元数据继续保留动态实现，后续清理不要将这些必要代码误删。仅删除已经被新实现替代且无使用方的代码；Smoke/回归入口不能因文件名或暂未运行而删除。

本轮仅进行了源码阅读和手动差异审查。**未执行构建、自动测试、架构门禁、Visual Studio 设计器打开/保存检查、Windows 启动检查或 DPI 界面验收。** 提交使用 `[skip ci]`，不借提交自动扩大已授权的测试范围；任何验证均遵循 `AGENTS.md` 的授权约定。

完成验收必须分别记录：源码迁移、编译、设计器打开/修改/保存后重新打开、运行交互，以及目标分辨率/DPI 结果。只有 Windows 上实际验证过设计器和运行界面，才能报告对应页面验收通过。
