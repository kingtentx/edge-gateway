# AntdUI 与 WinForms 设计器重构记录

更新日期：2026-10-27

视觉规范统一遵循 [AntdUI-Demo 样式规范](ui-antdui-style-guide.md)：全部按钮采用官方基础样式及交互状态，不逐页覆写配色。样式适配不改变下方 Designer 与动态代码的边界。

## 本次确认的实施边界

采用“固定界面使用设计器，动态内容使用代码”。判断依据是控件结构是否随业务变化，而不是控件中显示的值是否变化。**新增了 Designer 文件、只放了空容器，或把 BuildPage/控件工厂搬进 Designer，都不等于设计器迁移完成。**

| 区域 | Designer 必须真实定义并挂入控件树 | 后台允许处理 |
|---|---|---|
| 主窗体 | 导航、顶栏、页面宿主、底部反馈区 | 导航事件、状态赋值、已有控件的响应式重排 |
| 设备与点位 | 工具栏及固定按钮、搜索框、表格和固定列、菜单入口 | 设备/点位行、选择与滚动恢复、操作状态、按目标生成的菜单项 |
| 数据库 | 固定页签、连接表单、测试/检查/保存按钮、映射表格框架 | 实际数据库表列表、按表结构生成的映射行、映射值与预览数据 |
| 平台与日志 | 固定分组、所有已知配置字段、页签和应用/重置按钮 | 枚举选项、草稿绑定、禁用/显示状态、日志结果与运行状态 |
| 配置弹窗 | 每个具体弹窗的固定表单、专属页签、标题和底部操作区 | 驱动专属通信参数、校验、业务调用及保存反馈 |
| 趋势与插件 | 图表/详情宿主、固定筛选区、刷新/管理按钮 | 曲线采样点、状态数值、插件参数与说明等元数据内容 |

设备名称、采样周期、数据库地址、Broker 主机、日志保留策略等字段属于固定表单，不得以“数据驱动”为理由留在后台创建。运行状态的数值可以动态更新，但固定状态标签和固定指标卡片也必须在设计器中存在。

## 源码组织要求

`Form/View.Designer.cs` 使用直接实例化、属性赋值、明确的父子关系和命名事件绑定，保留设计器能够维护的标准初始化结构。不得在 `InitializeComponent` 中调用控件工厂、通过循环/反射创建固定控件、访问运行配置或服务、执行数据库/驱动通信，或放入业务事件的匿名实现。

`Form/View.cs` 保存构造、响应式布局、事件处理、数据绑定及资源生命周期；业务保存仍通过 `IGatewayApplication`。固定控件只初始化一次，运行时不要再创建一套替代控件或重新包装整个固定表单。确需动态创建的参数放入明确命名的动态宿主，并负责取消、事件解绑和释放；刷新不应重建固定页面。

设计时构造必须不依赖真实数据库、驱动目录、采集进程或现场配置。共享基类具有 Designer 不能代替每个具体弹窗的固定字段迁移。静态表格的行数据不是控件结构，不把实时数据逐条固化进 Designer。

保持 .NET 8、Windows Forms、PerMonitorV2 和 96 DPI 逻辑基线；页面继承父窗体缩放，避免重复缩放。保持设备稳定 ID、配置原子提交、草稿保留、菜单与键盘操作、关闭到托盘和安全退出语义。采集调度、协议驱动、SQLite 配置和外部库写入不因界面重构而改变职责。

## 本轮源码调整（2026-10-27）

在现有 `main` 上继续实现。八个页面和具体编辑器均将固定控件、字段标签、分组、列结构和操作区直接定义在对应 `.Designer.cs`，业务文件负责绑定、事件、已有控件的响应式布局和资源释放。

| 区域 | 本轮迁移 |
|---|---|
| 主窗体 | 固定导航、顶栏、页面宿主、反馈区；无服务依赖的设计时构造 |
| 总览 | 四个设备指标、健康指标、CPU/内存图表及磁盘宿主、快捷操作；磁盘卡片与曲线数据动态更新 |
| 设备与点位 | DevicesPageView.Designer 定义设备筛选、操作栏及设备表；DevicePointsDialog.Designer 定义独立点位弹窗的标题、搜索、操作栏、点位表及关闭/反馈区；数据行和按稳定 ID 生成的菜单项动态绑定 |
| 实时、历史、诊断 | 筛选字段、日期范围、查询/导出/刷新按钮、固定列和图表宿主 |
| 数据库 | 连接与写入组列表、固定操作；连接表单、写入组三页及映射列结构迁入各自 Designer |
| 平台 | 固定四页及全部已知字段、操作区；运行时只绑定草稿、选项和命令 |
| 日志 | 固定设置表单、运行日志/采样数据页；共享 `LogArchivePageView` 定义筛选、操作与列，运行时切换已有列和结果 |
| 编辑器 | 设备、点位、通道、数据库连接/写入组/预览、写值、点位/设备导入、驱动管理/详情均有独立 Designer |

`Editors.cs` 和 `DatabaseEditors.cs` 按具体窗体拆分，项目文件声明窗体类型与 Designer 从属关系。公共 `EditorDialog`、`EditorFeedback` 和输入容器也使用自己的 Designer；具体窗体提供不访问服务的无参构造。

采用 AntdUI 2.4.16：按钮、文本和密码、复选框分别基于 `Button`、`Input`、`Checkbox`；下拉、数值、日期和页签通过 `GatewaySelect`、`GatewayNumber`、`GatewayDatePicker`、`GatewayTabs` 继承官方 `Select`、`InputNumber`、`DatePicker`、`Tabs`。左侧为 Designer 中声明的 `AntdUI.Menu` 和八个固定菜单项，支持收缩为图标列。`GlobalUsings.cs` 的别名保留字段绑定接口，控件没有嵌入原生 ComboBox 或 NumericUpDown。输入容器只负责布局，边框和弹层由 AntdUI 绘制。2026-10-29 起全部表格使用 GatewayTable : AntdUI.Table，固定列仍在各自 Designer 中声明；字段映射采用 CellSwitch、Select 与 Input，点位选择列表按可见数据行创建 AntdUI Label 和 Switch。窗口、卡片、曲线、容量条与提示确认也改用官方组件，详见 [迁移清单](ui-antdui-migration.md)。详情及本轮验证见 [官方控件与交互修复](ui-antdui-controls.md)。许可证和包归属见 `LICENSES` 与 `THIRD-PARTY-NOTICES.md`。

固定表单直接持有输入容器和编辑器，后台不再用 `InputSurface` 重新包装固定控件。动态驱动专属字段继续使用公共字段入口。实时数据、外库 schema 映射行、曲线点和插件元数据继续动态生成；配置保存仍等待应用层提交成功，错误保留原弹窗和输入。

### 分组与通道管理（2026-10-27）

`DevicesPageView.Designer.cs` 创建两个独立管理按钮；`ConfigurationCatalogDialog.Designer.cs` 创建固定标题、操作栏、三列表格、反馈区和关闭按钮，运行时只绑定目录数据和应用命令。`DeviceGroupEditor.Designer.cs` 创建名称字段，通道编辑复用 `ChannelEditor.Designer.cs`。设备分组可编辑下拉仍在设备 Designer 中创建，选项从已保存目录绑定。源码边界、设计器与运行证据见 [管理功能记录](device-catalog-management.md)。
