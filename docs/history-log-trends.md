# 日志历史与趋势

2026-10-28：历史页面新增“采样日志 / 外部数据库”来源选择，默认使用采样日志，无需配置数据库连接。

## 使用

1. 在“历史与趋势”选择数据来源、设备、点位和时间范围。
2. 日志来源可设置扫描上限，默认 32 M，最大 64 M；返回条数默认 1000，最大 2000。外部数据库来源仍选择标准点行写入组，最大返回 10000 条。
3. 点击查询后查看记录；选择单个数值点位显示趋势。坏质量、空值、非数值处断线，曲线至少需要两个正常数值样本。
4. 导出使用整份已查询结果，不受当前分页影响。修改来源或筛选后，旧摘要、曲线和导出仍绑定上次结果，直到新查询成功。

日志来自采集服务器程序目录的 `logs/data`，读取新格式和已有包装格式。保留原始值、工程值、质量、时间、单位和错误；设备和点位按稳定 ID 精确筛选。Application 承接用例，Service 复用归档扫描，界面不读取文件或解析 JSON。所有固定输入在 HistoryPageView.Designer.cs 创建。

## 结果边界

日志只包含当前仍保留的采样。扫描从近期文件尾部开始，受扫描容量、返回条数、4 M 结果容量和 1000 文件边界约束；查询摘要展示受限及坏行情况。扩大时间范围不会自动扩大扫描额度。轮转清理、停用日志或队列丢弃的数据无法恢复，未触发扫描限制也不等于完整历史。趋势目前只按已记录的质量断线，不推断未记录期间的停机间隔。

外部数据库失败不会自动改用日志。数据库未配置时，该来源查询不可用，可手动切回采样日志。SQLite 继续仅保存配置。

日志历史 CSV 首行是已执行查询说明，包括来源、准确时间范围、稳定筛选 ID、条数/扫描上限、警告；第二行为列名，后续为所有查询记录。外部数据库 CSV 格式保持原样。
