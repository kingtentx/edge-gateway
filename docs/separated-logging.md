# 运行日志与采样数据分离

更新：2026-10-26。

## 页面与查询

日志页依次为：

1. **日志设置**：运行事件最低级别、单文件大小、文件数和保留天数；采样开关及独立的单文件大小、文件数和保留天数。共享所在卷的剩余空间保护与恢复余量，可热应用，保存失败保留输入与已保存配置。
2. **运行日志**：从程序根目录 `logs` 查询事件，可筛选本地起止时间（包含边界）、最低级别和关键词。原来最近 500 条内存事件列表由持久化查询替代，完整内容双击查看。
3. **采样数据**：只查询 `logs/data`；支持设备/点位名称包含匹配（忽略大小写）或完整 GUID、质量、时间及关键词。名称筛选可追查已删除设备的文件记录。同名设备可用完整标识区分。表格显示原始值、工程值、质量及错误，空失败值不伪装成零。

页签各自持有筛选、取消令牌、结果和滚动位置。查询期间修改输入不会改变正在执行的请求，完成后保留“需重新查询”提示；失败和取消不清除上次结果。手动查询刷新，设备刷新不重绑查询表格。

文件范围和记录类别双重过滤，采样查询不消耗运行文件的扫描额度，反之亦然。保留原有有限文件尾部查询：最多 1000 个文件、1–64 M 扫描、1–2000 条、4 M 原始结果载荷；部分覆盖、损坏、轮转删除等均报告，不宣称导出全部历史。查询不依赖外部业务数据库。

## 文件与导出

文件路径及 JSONL 写入格式保持不变，两类分别轮转；默认均为 10 M/30 份/30 天。运行日志级别只影响系统事件，采样开关单独控制采样记录。磁盘保护及有界后台队列仍共用，丢弃与失败可见。

CSV 或 JSONL 导出均绑定已执行的查询快照，首行包含时间、类别、筛选及受限说明。CSV 使用 UTF-8 BOM、CRLF、引号转义与公式前缀保护；长整数字符串加文本前缀，避免 Excel 直接打开时丢精度。JSONL 保留原始记录和 JSON 值类型。导出到临时文件后原子替换，取消不改原目标；禁止导出到运行日志目录或任意其他扩展名。

## 配置结构与部署

模型/JSON 交换 schema 3 不变，新增采样文件策略三个字段有 10/30/30 缺省值。SQLite `logging_settings` 增加 `sample_max_file_size_mb`、`sample_retained_file_count`、`sample_retained_days` 强类型列；物理结构版本由 4 升为 5，17 张功能表数量不变，当前/上一份配置仍在同一事务保存。

按项目约定，旧库明确拒绝，不自动迁移或清空。本轮不打开或修改现场运行库，不覆盖正在采集的 Debug 输出。更新运行程序前先在旧程序导出整份 schema 3 配置并保管原目录，在新空目录启动新版后导入配置；驱动停用/插件与协议状态文件需按原部署安排保留，不能把新目录初始化误称为原库升级。
