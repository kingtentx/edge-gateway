# 第二阶段数据记录与可靠性

基线：PR #1 / 80e3be00d010cae29500b9112daa5dc0af5d4d03。保持 .NET 8、schema 3、SQLite 仅配置和无 OPC UA 对外服务器。

## 操作入口

- 数据库 → 采集写入组 → **检查与预览**：读取真实表字段，显示字段存在性、必填/默认/生成规则和当前采样转换结果。设备运行中可只读预览，不保存配置、不创建表、不插入数据。无真实活跃采样时明确显示未就绪。字段转换与运行时使用同一转换器。预览不是权限、唯一键、触发器或 precision/scale 的完整写入保证。
- 数据库 → 数据库连接：新增队列载荷/峰值、失败/重试/超时、在途批次/最近耗时。队列计数包含已取出但尚未确认的批次。高水位为行数或字节额度达到 80%；满额拒绝新记录并计数，绝不让采集等待数据库。
- 日志 → 日志设置：最低剩余空间默认 256 MiB，恢复余量默认 64 MiB。后台检查容量，低空间暂停文件写入；达到阈值加余量才恢复。磁盘探测失败按保护状态处理。保护期间丢弃不补写，内存运行记录仍保留；不删除其他业务文件。
- 日志 → 文件查询与导出：按起止时间、最低级别、关键词和是否包含采样筛选；单次最多 2000 行、扫描最多 64 MiB、结果原文最多 4 MiB。以文件尾部为起点扫描，受限结果明确标记，过滤不能扩大历史覆盖范围。取消查询保留旧结果；导出明确绑定**已经执行的查询快照**，不是尚未提交的筛选值。
- 导出格式为 JSONL，首行记录查询条件及完整性说明；在目标目录内临时写入并原子替换，不能导出覆盖运行日志目录。取消不替换现有文件。导出可能包含采集业务值，应按业务数据权限保存。

## 故障语义

永久错误（配置、认证、表结构、约束等）不在同一批次中反复重试；暂态错误有限退避并加入抖动。标准点表重试保持 event_id；自定义表的提交结果不明时仍可能重复，业务唯一键与幂等策略需显式设计。

连接器超过期限却没有结束时，该工作任务仍持有原批次配额并隔离，不启动重叠重试，不假装取消令牌已终止原调用。停止采用既有有界宽限；未退出工作任务完成前禁止重新启动。其他写入组/连接不等待该调用。

## 可执行验证

```powershell
dotnet test tests/EdgeGateway.Tests -c Release
./scripts/smoke-test-winforms.ps1
# 受控模拟采样 + 慢连接/周期故障，不是真实 PLC 或真实数据库测试
dotnet run --project tests/EdgeGateway.Endurance -c Release -- --seconds 45 --output artifacts/endurance
# 专门的长稳环境执行，不能把 45 秒结果冒充 24 小时结果
dotnet run --project tests/EdgeGateway.Endurance -c Release -- --seconds 86400 --output artifacts/endurance-24h
```

真实数据库测试见 tests/EdgeGateway.DatabaseIntegration/README.md，入口支持 mysql、postgres、oracle。仅使用授权的专用测试库；必须显式设置 EDGE_DB_TEST_ALLOW_DDL=1。测试创建随机命名的测试表，并在 finally 中仅删除其自身记录的表。请勿连接生产库。

CI Oracle 使用实际 Oracle Free 23 容器，非数据库模拟器；覆盖连接/元数据、批量数组写入、重放、UTC/Unicode/精确数值、跨批回滚、锁等待取消。是否实际通过，以对应提交的 CI 证据为准。

## 仍须单独验收

1. 客户指定版本 Oracle、TLS/证书、最小权限账号、真实断网和实例重启恢复。
2. 真实设备连续采集 24–72 小时，核对断线质量、重连、队列损失、内存增长趋势与磁盘保护。
3. Windows 11 / Server 实际 100%、125%、150%、200% DPI，1920×1080、2560×1440、3200×2000，以及跨显示器移动。CI 工作区矩阵与实际高 DPI 实机不是同一项验证。
4. 不声明内存队列断电不丢数据，不声明自定义表 exactly-once，也不以短时测试宣称现场吞吐保证。
