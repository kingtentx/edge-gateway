# 字段映射编辑优化（2026-10-31）

字段映射第一列改为官方下拉“写入方式”：

- **不写入**：不生成该列的 INSERT 参数，使用数据库默认值或 NULL。值来源、点位、类型、常量均不可编辑；无默认值的非空字段仍在保存时拒绝遗漏。
- **采样取值**：选择工程值、原始值、标识、名称、时间等来源；整行模式按来源绑定点位。记录编号与记录时间无需点位。
- **手动常量**：只编辑常量和转换类型，允许文本空字符串；数值/时间等无效常量保存前报错。

自增/生成字段保持只读且不写入。切换方式保留当前编辑会话中的常量和采样来源草稿；不写入字段不持久化其闲置草稿。固定按钮和列在 Designer 中创建，数据行动态绑定，没有新增自绘组件。

## 字段匹配与保存

新建空映射首次读取字段时，匹配已知标准字段名（忽略大小写），例如 event_id → 记录编号、device_id → 设备标识、tag_id → 点位标识、timestamp → 采样时间、value_text → 工程值。未知字段保持不写入，由用户决定用途，不再将任意必填列默认映射为工程值。

已有配置和刷新保留编辑，包括主动选择的不写入、常量草稿、绑定点位及选择/滚动位置。需要修正旧映射时点击“按字段名匹配”，确认后替换已识别字段的来源和转换类型，未知字段保持原样；最终仍需保存配置。

“自动”在保存时按目标字段元数据解析并写入具体转换类型；例如 varchar 的工程值转为文本，timestamp 转为时间。时间字段不接受明显错误的文本/数值转换；自动工程值来源用于时间列时要求选择采样/记录时间，或明确选择时间转换并预览实际值。保留数据库类型精度括号后的时区信息。未知数据库类型仍为 Auto，不能保证所有厂商自定义类型可写。

这不是业务数据库修复脚本：不会改变现有连接、写入组或缓冲记录，也不重放旧失败批次。真实 INSERT 权限、唯一键、触发器与字段长度等仍须业务数据库实际验证。
