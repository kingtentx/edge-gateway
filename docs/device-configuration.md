# 设备表行内配置

日期：2026-10-23（Asia/Shanghai）。适用于 .NET 8 WinForms 采集网关。

## 使用方式

1. 打开“设备与点位”。设备表每行显示运行状态、“启动”“停止”以及右侧“配置”入口。
2. 点击目标设备行的“配置”，或双击该行的设备名称、驱动等普通数据列。两种入口均打开同一个专用配置弹窗，按被点击行的设备 ID 定位，不受此前选中行影响；弹窗标题显示设备名称，当前驱动固定。
3. 弹窗默认显示“采集设置”。首行“启用设备”复选框回显当前设备状态，可勾选启用或取消勾选停用；下方可修改采集周期、通信超时。切换到连接或驱动参数页配置该设备的协议参数。
4. 点击“确定”后，程序对完整候选配置进行校验并自动保存，成功后才更新当前设备。点击“取消”或关闭弹窗不会修改原设备；校验或保存失败时保留原配置并提示错误。顶部不再提供“保存配置”。

任意设备采集运行期间，所有设备的配置入口均显示“查看”，点击该入口或双击普通数据列均打开只读弹窗并仅提供“关闭”；“启用设备”同样不可修改，停止全部运行设备后才可编辑。工具栏“编辑设备”继续用于设备名称、分组、驱动切换，也可修改同一启用状态；点位仍在下方点位表维护。

“启用设备”对应保存的设备配置 `Enabled`，决定该设备是否允许启动；勾选并确认不会立即开始采集，保存成功后仍通过该设备行的“启动”操作。

“启动”“停止”“配置/查看”属于操作列，不走普通数据列的双击入口，避免单击处理后再次打开配置弹窗。

单设备启停、自动保存和平台草稿的完整行为见 [单设备启停与自动保存](device-control-autosave.md)。

## 参数来源与差异

源项目基准固定为 [`iioter/iotgateway@8de442a7`](https://github.com/iioter/iotgateway/tree/8de442a7dec52d2993d1e9667d799846936d681b)。源项目 `DriverService.AddConfigs()` 反射驱动的 `ConfigParameterAttribute`，使用属性名作为键、描述作为标签、真实实例值作为默认值，枚举按名称保存。新窗口复用本项目已迁移的同一份元数据，不维护第二份硬编码的迁移驱动参数表。

| 当前驱动 | 配置字段示例 |
|---|---|
| 内置 `modbus-tcp` | 主机地址、TCP 端口、站号 |
| 内置 `modbus-rtu` | 串口、波特率、数据位、校验位、停止位、站号 |
| 内置 `simulator` | 采集周期、超时；无需网络或串口连接参数 |
| `PLC.SiemensS7` | CPU 类型、IP、端口、Rack、Slot |
| `PLC.MelsecMc` | CPU 类型、IP、端口 |
| `PLC.ModBusMaster` | 主站类型、IP/端口、串口参数、从站号 |
| `PLC.OmronFins` / `PLC.AllenBradley` | IP、端口 |
| `OPC.UaClient` | URI、迁移版已有的安全策略与 PKI 目录 |
| `OPC.DaClient` | 服务器 IP、OPC Server 名称 |
| `CNC.Fanuc` / `CNC.Fanuc.H` | IP、端口；Hsl 版本保留授权码环境变量名 |
| `CNC.MTConnect` | MTConnect URI |
| `Other.Toledo` | IP、端口、帧长度及源驱动元数据字段；其 DataBits 表示 TCP 帧长度 |
| `Mock.TcpClient` | IP、端口、连接类型 |

所有迁移驱动原有参数均继续保留；既有值优先回显，缺失键才使用驱动默认值。未知参数不会被弹窗静默删除，仍交由工厂验证报告。无效导入枚举或越界初始值保留显示，确认时明确报错，不自动替换成另一个值。

设备标识 `DeviceId` 只读绑定设备 ID；`Timeout` 和 `MinPeriod` 绑定“采集设置”中的超时、采集周期，修改后同步刷新。这些绑定字段不重复写入 `Properties`。“启用设备”直接读取和提交设备模型的 `Enabled`，同样不是驱动参数字典中的额外键。枚举、整数、布尔、文本、密码遮罩和参数说明沿用统一参数面板。

本轮不引入源 Web 项目的 `DataSide` 云端属性上传范围或其它平台消息功能。协议参数与现有网关采集、保存流程保持一致。

## 实现与保护

- `MainForm.Configuration.cs`：行内“配置”单击与普通设备数据列双击复用同一个 `DeviceConfigurationDialog` 入口，通过被点击行的稳定设备 ID 定位，并采用相同的运行时只读保护。双击事件排除启动、停止、配置等操作列，避免额外弹窗；工具栏“编辑设备”继续打开通用设备编辑器。
- `DeviceConfigurationDialog.cs`：默认打开“采集设置”，首行复选框回显并提交设备 `Enabled`。使用内部深拷贝，配置成功前不发布结果；设备 ID、名称、分组、驱动与点位集合保持不变。提交时仅隔离与此窗无关的点位校验，所有驱动参数仍由原工厂校验，包含启用状态的完整候选配置在确认后的统一提交入口校验，原子保存成功后再更新当前配置。取消、校验或保存失败均保留原启用状态；只读模式禁止修改复选框。
- `DriverParameterPanel.cs`：复用驱动元数据与现有值，支持明确的只读模式和“采集设置”提示。
- 新列使用随 DPI 调整的最小宽度，弹窗复用 `EditorDialog` / `DpiAwareForm` 的滚动、工作区约束及固定操作栏。
- 标题行与长说明使用独立布局，避免说明文字挤压标题导致中文竖排；界面检查同时核对中文列标题及弹窗标题的实际可见尺寸。
- 自绘按钮在前景绘制开始时完整填充背景，处理 `ButtonBase` 的 Opaque 绘制路径下圆角外区域可能残留像素的问题。
