# 运行中配置查看与实时筛选（2026-11-01）

本次优先优化用户日常查看与筛选，不调整采集调度、设备读写互斥、数据库队列或配置 schema。

## 数据库运行中查看

有设备运行时，数据库页原“编辑连接 / 编辑写入组”变为“查看连接 / 查看写入组”，双击列表也可打开。没有选择记录时入口不可用。停止全部设备后恢复编辑入口。

查看复用已有 Designer 表单，展示打开时已保存配置的快照；密码仍由原密码框掩码。查看模式不绑定保存回调，确认按钮隐藏，共用保存入口拒绝只读提交。建表、读取外部元数据及编辑字段的动作不可用。点位分组/设备树、搜索、页签、列表滚动可操作，复选项只读；切换搜索不会解除只读。映射表保留阅读与滚动，禁止编辑。

读取的是已有配置，无新增轮询、外库请求或后台任务。窗口打开后即使运行状态改变，该窗口仍保持只读，需要关闭后重新打开。数据库设置的全停约束继续由应用层与运行时执行，未实现写入组热更新。

## 实时监控

结果摘要显示设备数、点位总数及本页范围，翻页和更改每页条数同步更新。空结果提示清除筛选。Designer 增加“清除筛选”，恢复全部分组、全部设备、空搜索及第一页；普通定时刷新继续保留阅读位置。
