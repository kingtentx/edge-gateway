# 八页面定时刷新检查

日期：2026-10-27。承接数据库页抖动修复，检查其他页面是否存在相同的整表重绑、状态文字中间态和布局反复变化。

## 源码检查与修复

| 页面 | 检查结果 |
|---|---|
| 运行总览 | 卡片直接更新，磁盘按稳定名称复用控件；曲线正常重绘，没有整表重绑 |
| 设备与点位 | 定时更新状态单元格；配置或筛选变化才重绑列表，没有每秒重新装配页面 |
| 实时监控 | 发现同类问题：每次快照都替换 DataSource；已改为按设备 ID/点位 ID 更新变化行 |
| 历史与趋势 | 执行查询时替换结果，定时刷新不重新执行查询或绑定结果 |
| 通信诊断 | 已使用 BindingList 和稳定键更新变化行，无变化时不重绑 |
| 数据库 | 保留完整状态一次更新；按行更新方法移到 GridViewState，与实时页共用 |
| 平台与系统 | 定时刷新更新命令可用状态和完整说明，不重新绑定草稿字段 |
| 运行日志 | 运行/采样查询仅在查询操作时替换结果；文件状态显示在固定高度的可滚动输入区 |

共享 `GridViewState.UpdateRows` 保留绑定列表和行实例。仅值发生变化时通知对应行；键集合或顺序变化时重建数据源并恢复阅读位置。现有配置/筛选用的 `Rebind` 入口保持原有语义，固定控件继续在 Designer 中维护。
