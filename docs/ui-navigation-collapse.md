# 左侧菜单收缩与展开修复

日期：2026-10-27。

## 原因与修改

收缩按钮原有两个 Click 处理器，先修改菜单/品牌显示并立即布局，再调整侧栏列宽。隐藏 AutoSize 品牌区会同步进入嵌套布局，列宽样式虽然已变化，TableLayoutPanel 缓存的实际列宽却可能仍是展开宽度，出现只剩图标但左侧空白没有收起的情况。AntdUI 2.4.16 的 `Collapsed` 属性仅写状态；官方 `SetCollapsed` 才会同时重算菜单项布局。

现将收缩操作合并为一个处理器：暂停主布局和侧栏布局，调用官方 `SetCollapsed`，同步品牌、图标、无障碍名称与实际列宽，最后恢复布局。Designer 显式关闭 AntdUI 自动折叠，状态由收缩按钮统一维护。固定 Menu、MenuItem 和按钮继续在 Designer 中创建，没有改动业务配置。

## 横向收缩布局（2026-10-27 后续调整）

用户明确要求收缩后全部菜单图标和展开按钮排成一条横向栏。因此当前行为替代上文的 56 逻辑像素图标侧栏：收缩后隐藏左侧栏，顶部显示应用图标、八个 AntdUI 图标按钮和展开按钮，保持同一水平中线；主内容区使用全部窗口宽度。展开后恢复原有左侧文字菜单和底部收缩按钮。横向按钮提供页面名称提示、无障碍名称和当前页蓝色高亮，切换保留页面与筛选状态。

固定横向栏、应用图标占位控件和九个按钮全部在 MainForm.Designer.cs 创建并挂入控件树；后台只绑定应用图标、事件与页面状态。布局切换仍在同一次暂停/恢复布局中完成。横栏固定高 52 逻辑像素，内部行按剩余高度填充，避免隐藏控件初次布局产生过大的行高。
