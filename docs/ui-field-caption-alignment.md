# 字段标题与输入区水平对齐

2026-10-29：用户指出设备配置的“设备分组”等标题偏上，要求检查全部页面。

## 修改

- 公共 GatewayLabel 保留 MiddleLeft、Dock.Fill 标签由父布局分配的高度。AntdUI Label 在 Resize 时再次按 PSize 自动缩高，原先会使已填满行的标题退回文字高度；现在仅此类居中标签保留行高，GetPreferredSize 仍按实际字体、可用宽度和换行测量，供父布局决定所需空间。
- 设备、点位、通道、数据库连接/写入组、日志设置、导入及写值表单的字段标题使用与输入区相同的上下外边距；动态驱动参数通过 EditorDialog.Field 同步处理。
- 平台四个页签的字段标题在 Designer 明确使用 Dock.Fill 和 MiddleLeft，输入及开关的上下间距一致。
- 设备、实时监控、历史、运行/采样日志的横向筛选标题已有 Width 自动尺寸与 MiddleLeft，保留既有规则。分组编辑器的左右控件使用相同默认边距，通过公共标签修复对齐；首页、通信诊断和数据库列表的页面标题/说明不按字段标题改动。
- 固定控件保留在 Designer，使用官方标签渲染；未引入自绘、字体缩小或业务修改。
