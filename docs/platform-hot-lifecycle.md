# 平台连接热维护

2026-11-02：平台连接、上报策略和远程控制设置支持在设备采集中应用。平台任务具有独立取消源，停止和重建平台任务不取消设备会话，不重启采集输出或数据库写入任务。

## 操作

- 编辑平台连接、上报策略或远程控制后点击“应用设置”。正在运行的平台任务先退出旧连接及 RPC，再按已保存的新设置启动；实际连接失败由诊断、日志与退避重连显示，不将配置保存成功当作连接成功。
- “停止平台”停止新快照生成、补传发送和 RPC，保留未确认的持久消息。设备采集、采样日志及数据库写入继续；停止期间不会另行积累新的平台快照。
- “启动平台”使用已保存设置，保留未应用草稿；须已启用平台上报。没有设备运行时也可连接及补传。显式启动后，停止最后一台设备不会关闭平台；由设备自动带起的连接仍随最后一台设备停止。
- 手动停止平台后，修改设置保持平台停止；点击“启动平台”才恢复。手动停止状态仅作用当前进程，不改变已保存的启用设置。程序重新启动仍遵循设备自动启动及平台启用配置。
- 网关标识、名称、自动启动和通信通道结构变更仍要求停止全部设备；页面会具体提示这类变更。整份配置替换继续保留原全停要求。

## 保存、队列及并发

Application 命令锁与 Runtime 生命周期锁串行化配置、设备启停、平台启停。平台相关设置变更先完成完整校验，再取消并等待旧平台的生成、发送和 RPC 任务，断开连接并清理传输层待处理的旧 RPC；在任务静止后重新核对积压和确认凭据，再原子保存。设备采样不等待这段平台维护。

平台类型改变且有积压时拒绝保存。同平台目标变化且有积压仍要求原有预览确认；配置版本、候选或队列发生变化后确认失效。运行中队列变化可能要求重新预览，可先停止平台再完成确认。报文保留原载荷与主题，不改写旧消息；失去发送确认的消息保留并可能重复发送。

保存失败或提交前取消，原配置和设备会话保留；原来运行的平台恢复原设置。保存提交后不响应调用方取消，完成运行时同步。主动停止后不会因新增设备或保存平台草稿而被意外带起。应用成功后启用状态为关闭时不启动平台。

固定按钮及布局由 PlatformPageView.Designer 创建，使用公共 GatewayButton 默认样式；界面通过 IGatewayApplication 调用，Release Worker 通过现有命名管道传递命令。未新增配置字段或数据库版本。
